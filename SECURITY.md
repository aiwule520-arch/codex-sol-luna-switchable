# Security Policy

## Supported versions

Security fixes are provided for the latest released minor line.

## Reporting

Please do not open a public issue containing credentials, API keys, private source code, customer data, private logs, or sensitive local configuration.

For a security-sensitive problem, use GitHub's private security advisory/reporting feature if enabled for the repository. If private reporting is unavailable, open a minimal public issue that contains no exploit details or sensitive data and asks the maintainer for a private contact path.

## Scope

This project installs local Codex configuration files. It does not operate a hosted service, store credentials, or send telemetry.
